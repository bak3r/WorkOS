# Beliefs

What you take to be true about engineering after long attention. Each section captures a position worth defending.

## On correctness

A test that cannot fail proves nothing. Every check should name the bug it would catch.

## On design

The simplest design that survives the known failure modes beats the clever one that survives imagined ones.

## On ownership

Owning a system means being able to explain how it fails, not only how it works.
