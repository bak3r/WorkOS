# Contacts

> Colleagues and stakeholders the DA should know about — short entries, working context.

## Format

Each entry: name, role, context, handle (optional), last touch (optional).

```
### Name
**Role:** manager / product owner / QA / peer developer / tech lead / stakeholder / other team
**Context:** one-line why they matter (what they own, what they decide, what to ask them)
**Handle:** GitLab / Jira username or work email (if relevant)
**Last touch:** YYYY-MM-DD (optional)
```
